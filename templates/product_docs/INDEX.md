# INDEX — реестр живой документации

Правила — `README.md`. Ссылки на требования — по ID (текст в `output/data/<project_id>/specs/`, граф — `…_traceability_repo.json`).

## Бизнес-функции

Статусы: `idea` → `planned` → `in_dev` → `implemented`. Для архитектора берутся только `planned` с утверждёнными требованиями.

| БФ | Название | Требования | Компоненты | UI | Релиз | Карточка |
|---|---|---|---|---|---|---|

Пример строки таблицы: `| BF-01 | Название функции | FR-001, 002; BR-001 | component_name | KON-5 | MVP | ссылка вида markdown-ссылка на карточку |`

Сквозные: _требования платформы, не принадлежащие одной БФ (например, NFR-001, 003)_ — заменить строку списком ID, когда он появится.
